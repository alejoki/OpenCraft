# S01: winit 0.30 ApplicationHandler migration

**Milestone:** M001
**Slice:** S01

**Goal:** Migrate src/main.rs from winit 0.29's deprecated closure run() API to winit 0.30.13's ApplicationHandler trait with zero behavior change: state moves from closure captures into a GameApp struct, the window and GPU stack are created in resumed() via ActiveEventLoop::create_window (idempotent guard), every WindowEvent/DeviceEvent arm moves verbatim into window_event()/device_event(), request_redraw moves to about_to_wait(), and ControlFlow::Poll is set once before run_app(). Cargo.toml bumps winit to 0.30 and Cargo.lock is updated. Acceptance: cargo build warning-free, cargo clippy clean, and a bounded launch smoke (game runs ~10s on the migrated loop without panic) passes; the full manual gameplay-parity checklist is documented for human follow-up. S01 provides the migrated event loop and Arc<Window> to S03/S04.
**Demo:** After this: cargo run launches the game on winit 0.30's ApplicationHandler loop with movement, block break/place, and raycast behaving identically to pre-migration (manual smoke check), and cargo build + cargo clippy are clean with winit = 0.30.

## Must-Haves

- cargo build completes warning-free with winit = 0.30; cargo clippy is clean; launch smoke script passes (game process runs ~10 seconds under the ApplicationHandler loop without panicking or exiting early); Cargo.lock resolves winit 0.30.x; every event arm in src/main.rs is a verbatim move from the 0.29 closure (sensitivity 0.0022, !event.repeat guards, Focused(false) reset, ungrabbed-click regrab, close-saves-world all preserved).

## Proof Level

- This slice proves: Executed proof: warning-free cargo build (deprecation warnings would expose removed 0.29 patterns — a compile probe proved a warning-free target exists), clean cargo clippy, and a bounded automated launch smoke (process survives ~10s on the migrated loop with no panic in output, exit via timeout). Full gameplay behavior parity (WASD/jump/crouch/sprint/fly/F5-save/Escape-grab/LMB-break/RMB-place/hotbar/render-distance/resize/close-save) is inherently a manual check and is recorded as NEEDS-HUMAN follow-up, not fabricated as automated evidence.

## Integration Closure

Provides the winit 0.30 ApplicationHandler event loop (resumed, window_event, device_event, about_to_wait) and window creation via ActiveEventLoop::create_window returning Arc<Window> for the wgpu 0.19 surface — the exact boundary contract S03 (UI foundation, CursorMoved/CursorLeft routing) and S04 (settings menu, InputState::reset routing) consume. src/render/context.rs is verified unchanged across the bump (rwh 0.6.2 on both sides), so no rework is pushed downstream.

## Verification

- None — window-title FPS/chunk/quad readout and stderr logging behavior are preserved verbatim; no new observability surfaces are introduced.
