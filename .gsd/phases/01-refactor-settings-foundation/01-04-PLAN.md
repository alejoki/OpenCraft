# S04: In-game settings menu: rebind, adjust, persist

**Milestone:** M001
**Slice:** S04

**Goal:** Deliver the in-game settings menu: a pure-logic menu state machine (layout, hit-test, clamped adjustments, rebind capture) in a new src/ui/menu.rs, wired into main.rs so Escape opens the menu (releasing cursor grab, resetting InputState), the 7 gameplay keybinds route through the loaded Settings keybind map with press-to-rebind and duplicate/unsupported-key rejection, sensitivity/FOV/fullscreen/vsync apply live and save on every accepted change, and the roadmap proof (rebind jump to ShiftLeft, quit, relaunch, binding still in effect and shown) holds via file-based restart persistence plus NEEDS-HUMAN interactive UAT.
