3. Run `cargo build` — expect exit 0. Run `cargo clippy` — expect exit 0 (no errors; remaining warnings are pre-existing world/terrain lints untouched by this slice).
4. Behavior matrix, each pinned by a named test:
   - Round-trip: non-default settings (e.g. jump_or_up = ShiftLeft, sensitivity 0.005, fov 90.0, vsync true) save -> load yields identical Settings, zero warnings — `round_trip_preserves_non_default_settings_with_zero_warnings`.
   - Defaults round-trip with zero warnings — `defaults_round_trip_exactly_with_zero_warnings`; saved bytes match the documented format — `saved_file_matches_the_documented_format`.
   - Missing file -> defaults + exactly 1 warning, no panic — `missing_file_yields_defaults_with_exactly_one_warning`.
   - Syntactically invalid TOML -> all defaults + 1 warning — `syntactically_invalid_toml_yields_all_defaults_with_one_warning`.
   - Per-field fallback: bad fov type keeps valid keybinds and sensitivity, warning names fov — `bad_fov_type_falls_back_while_valid_fields_survive`.
   - Unknown keys/sections/actions silently ignored, values still load — `unknown_keys_sections_and_actions_are_silently_ignored`.
   - Out-of-range values clamped with warnings both directions — `out_of_range_values_above_maximum_are_clamped_with_warnings`, `out_of_range_values_below_minimum_are_clamped_with_warnings`; boundary values accepted without warnings — `boundary_values_are_accepted_without_warnings`.

   - Atomic save: creates missing parent dirs, overwrites existing file, leaves no tmp file behind — `save_creates_missing_parent_directories_and_overwrites_existing_file`, `save_leaves_no_tmp_file_behind_on_success`.

## Edge cases covered
- Missing individual keybind actions keep defaults silently (partial files are fine) — `missing_keybind_actions_keep_defaults_without_warnings`.
- Wrong-type keybind / mouse / video fields each fall back independently — `wrong_type_keybind_falls_back_with_warning`, `wrong_type_mouse_and_video_fields_fall_back_with_warnings`.
- Unparsable keybind string falls back to that field's default with a warning — `unparsable_keybind_string_falls_back_with_warning`.
- load() wrapper discards warnings and never panics — `load_discards_warnings_and_never_panics`.
- Valid minimal file parses with zero warnings — `valid_minimal_file_parses_with_zero_warnings`.
