# S03: UI foundation: glyphon text overlay + quad rendering

**Milestone:** M001
**Slice:** S03

**Goal:** Add a src/ui module rendering a live always-on stats text overlay (FPS/position readout) with glyphon 0.5.0 and a filled-quad renderer in a separate color-only render pass after the existing world pass, driven at the existing 0.25 s title-stats cadence, plus cursor position/enter/leave event capture into GameApp state. Concretely: Cargo.toml gains glyphon pinned to =0.5.0; src/ui/ provides the glyphon wrapper stack (FontSystem, SwashCache, TextAtlas, TextRenderer created once in resumed()) and a quad renderer (OverlayVertex reuse, TriangleList, alpha blend, pixel-space API); src/render/pipeline.rs render_frame gains a UI pass hook (a second begin_render_pass on the same encoder, color-only, LoadOp::Load) drawn between the world pass and submit/present; src/main.rs routes CursorMoved/CursorLeft into a cursor_pos field and drives the overlay text from the existing stats data. Verification: cargo build warning-free, cargo test (existing overlay-vertex test untouched + new quad-vertex unit test), cargo clippy with inherited lib warnings scoped per MEM007, and scripts/launch_smoke.sh (10 s bounded run, exit 124, no panic).
**Demo:** After this: the running game renders a live always-on text overlay (e.g. FPS/position readout) in a separate color-only render pass on the existing wgpu 0.19 pipeline, and cursor position/enter/leave events reach the app through the migrated loop.

## Must-Haves

- 1) cargo build is warning-free. 2) cargo test passes: the existing build_overlay_line_vertices unit test in src/render/pipeline.rs still passes untouched, and a new pure quad-vertex unit test (px→NDC conversion, 6 verts per quad) passes. 3) cargo clippy exits 0 with zero findings on the slice surface (src/ui/*, src/render/pipeline.rs, src/main.rs); the ~12 pre-existing lib warnings in src/mesh/*, src/world/* (MEM007) are inherited, not regressions. 4) bash scripts/launch_smoke.sh passes (10 s bounded run, exit 124, no panic) with the UI pass active — retires the glyphon-0.5.0-API risk and the pass-restructuring risk. 5) Visual legibility of the overlay over the running game is NEEDS-HUMAN (recorded in the UAT checklist): text overlay updates ~4 Hz, quads (a translucent panel behind the stats text) render, resize keeps text positioned.

## Proof Level

- This slice proves: executable-proof

No S02 dependency. Downstream S04 consumes the src/ui module (quad renderer, glyphon stack, cursor plumbing) for the settings menu.
